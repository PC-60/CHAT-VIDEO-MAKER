1 Chapter text

Works with both kinds of story. Chat-format stories ([Group Chat], User: message) are read directly. In normal prose, dialogue in quotes becomes chat bubbles. The speaker is found from words like says Ash or Brock asks. Lines it isn't sure about get a ? in step 3 so you can check them.

Got one narration for the whole story? Load the full subtitles and full audio here once. The tool finds every chapter inside them, so each chapter's video gets just its own part. MP3 or WAV works best for long audio.

3 Chat script

One message per line. Name: text is a bubble, >> text is a full-screen story card for prose scenes, [Chat name] switches to another group chat, ! Rose has left the chat is a system notice (a line with "typing" shows typing dots), and > text is a grey narration note. Chat-format stories are read as-is. A ? after a name means a guessed speaker: fix it or leave it, since the ? never shows in the video. To pin a time, start the line with [1:23.5].
